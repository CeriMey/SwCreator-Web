# Web Proxy branding

`ariya-black.svg` and `ariya-white.svg` are the official Ariya Consulting logos,
copied from IaAssistant's browser assets. Their originals are in
`AriyaConsulting/Identite visuelle/01_Logo/SVG/`.

`proxy.svg` is the Web Proxy relay icon shared with
`SwStack/extensions/browser-network/assets/`. Keep the application and extension
icons identical when updating the branding.
